Experimental prototype

Try TriviaPOD with Home Assistant.

A small demo to find out whether this device suits your Home Assistant setup. It is not a production-ready port.

Install over USB

Only M5Stack TriviaPOD TP-01-A — ESP32-S3, 32 MB flash, 8 MB PSRAM. A matching ESP32 chip alone does not make another board compatible.

1 · Connect

Use a USB data cable and a desktop browser with Web Serial, such as Chrome or Edge.

2 · Install & Wi-Fi

Select TriviaPOD, install the demo, then enter your Wi-Fi in the installer.

3 · Add in HA

Open Settings → Devices & services and add the discovered ESPHome device.

Installation replaces the current firmware. Keep your own backup/configuration if you need it. No shared Wi-Fi credentials or API key are embedded.

What you can try

  • Yellow: record a short phrase and hear it replayed from volatile RAM.
  • Tone: a 1 kHz / 2 kHz beep. No quiet 440 Hz option in the demo UI.
  • Touch, all three buttons, brightness, vibration and LED controls.
  • Battery/USB and IMU readings as Home Assistant entities.
  • Optional full-circle camera snapshots — set your own small JPEG URL in HA.

The visible version appears at boot, at the bottom of Checks, and in HA diagnostics.

Prototype limits

The generic export/provisioning build has not yet been flashed on hardware. Its hardware basis was tested on one TP-01-A; compatibility with other revisions is not established.

The generic demo uses an unencrypted local ESPHome API on your test LAN. For longer-lived use, compile your own unique API encryption key. Camera refresh is roughly one JPEG per second in bring-up, not video. RTC time, active charging, HA adoption/ring/media and some physical indicators still need evaluation.
